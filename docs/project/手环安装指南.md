# 将羽快记分板安装到小米手环 8 Pro

本指南说明如何把当前构建的 Vela 应用 RPK 通过已配对的 Android 手机安装到手环。安装过程由电脑通过 ADB 操作手机，再由小米运动健康的隐藏调试页把应用发送到手环。

## 当前安装包

- 应用包名：`com.yukuai.sync`
- 调试版本：`1.2.3`
- RPK 文件：`xiaomi-band-development/examples/yukuai-sync-dev/dist/com.yukuai.sync.debug.1.2.3.rpk`

## 安装前准备

1. 使用 Android 手机，并在小米运动健康中登录账号、完成小米手环 8 Pro 配对。安装期间手机和手环保持蓝牙连接。
2. 在手机开发者选项中开启 USB 调试，通过 USB 将手机连接电脑。手机弹出“允许 USB 调试”时，确认授权。
3. 确认电脑已安装 ADB，并能在终端执行 `adb version`。本项目脚本还需要 Android SDK 工具 `javac`、`d8`；按项目 README 配置 `ANDROID_HOME` 和 SDK 路径。
4. 安装脚本是 Bash 脚本。Windows 上请使用 Git Bash（或 WSL），不要在 PowerShell 中直接运行 `.sh`。
5. 让手环靠近手机，保持小米运动健康在后台可运行，并确保手机有足够电量。

## 推荐方式：运行部署脚本

打开 Git Bash，进入项目仓库目录。若仓库放在 `D:\Project\PRwithAI\YUQI`，Git Bash 中路径通常写作 `/d/Project/PRwithAI/YUQI`：

```bash
cd /d/Project/PRwithAI/YUQI/xiaomi-band-development
adb devices
```

`adb devices` 应显示手机序列号及状态 `device`。若状态是 `unauthorized`，解锁手机并确认 USB 调试授权；若没有设备，检查 USB 线、驱动和调试开关。

部署现有的 1.2.3 包，不重新构建：

```bash
./scripts/deploy.sh --project examples/yukuai-sync-dev --no-build
```

如需先重新构建再部署，去掉 `--no-build`：

```bash
./scripts/deploy.sh --project examples/yukuai-sync-dev
```

脚本会检查设备、准备安装工具并把 RPK 传到手机。出现文件选择器后，在手机上选择 `com.yukuai.sync.rpk`（脚本会提示位置/名称）；随后点选该 RPK，按小米运动健康的提示完成安装或手环传输。手机若弹出系统确认、权限或安装提示，请按提示完成。

如果要先卸载旧版本再安装，可使用：

```bash
./scripts/deploy.sh --project examples/yukuai-sync-dev --uninstall
```

卸载会移除手环上的该应用及其本地运行数据；需要保留比赛记录时不要选择卸载。

## 安装完成后检查

1. 等待手机端提示传输/安装成功，并让手机与手环保持连接直至完成。
2. 在手环应用列表中找到“羽快记分板”并打开。
3. 检查记分页、左右滑动、加减分、比赛设置、操作页长按重置及手机同步连接状态。
4. 若应用列表仍显示旧版本，退出应用列表后重新进入；必要时卸载旧应用，再按上面的步骤安装。

## 常见问题

- **脚本报告找不到手机：** 运行 `adb devices` 检查是否为 `device`；手机需解锁并接受授权。更换支持数据传输的 USB 线或 USB 端口后重试。
- **脚本找不到 `d8` 或 `javac`：** 安装 Android SDK 命令行工具及对应平台工具，设置 `ANDROID_HOME`，并确保 `javac`、`d8` 可从 Git Bash 找到。
- **RPK 未出现在文件选择器：** 确认部署脚本已完成文件推送，并按手机文件选择器中的 `Xiaomi-band` 目录查找；重新运行部署命令可再次推送。
- **手机显示成功，手环暂未出现：** 确认小米运动健康仍与手环连接，保持手机靠近手环并等待同步；再检查手环应用列表。
- **覆盖安装后行为仍像旧版：** 可能是版本缓存。使用 `--uninstall` 卸载旧版后重新安装；卸载会清除本地数据。
- **安装失败或连接中断：** 不要关闭小米运动健康；重新连接手机与手环，确认 ADB 授权，再运行部署脚本。读取脚本终端末尾的错误信息以定位缺少的 SDK 工具或文件。
