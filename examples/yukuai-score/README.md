# 羽快记分板

小米手环 8 Pro 的 Vela 单局记分应用。左右滑动可访问比赛设置、红蓝记分页、比赛操作与本次运行内的历史。默认羽毛球；单击对应区域加分，双击减分。右页长按红色按钮两秒重置，完成局在重置或确认切换比赛时进入历史。比赛数据仅保留在当前运行期间。

## 构建与测试

在本目录运行 `npm ci`，然后运行 `npm run build`。调试包位于 `dist/com.yukuai.score.debug.1.1.0.rpk`。也可用 AIoT IDE 打开本目录，选择 `xiaomi_band_pro` 模拟器并点击调试。运行 `node tests/scoring.cjs` 验证计分、切换、重置和历史。

模拟器与真实手环的触摸行为可能不同，安装到真实设备后需验证单双击、滑动、长按和布局。当前包使用工具链的调试签名。
