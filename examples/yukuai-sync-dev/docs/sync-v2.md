# 同步协议 2：开发验证记录

2026-11-06，Android / 手环 1.2.0，包名均为 com.yukuai.sync，匹配本地 Android 调试证书。

手环负责所有共享比赛状态的最终保存。手机计分发送 command，字段为 protocol=2、id、session、baseRevision、controlEpoch、action；操作包括 score/undo/reset/sport/display/names/requestControl/releaseControl。每次仅一条未确认手机指令，手机持久化后发送并每两秒重试。手环先核对编号去重，再校验比赛、版本、控制权代次；只接受手机控制状态下的修改。

手机申请接管需手环确认，确认时控制权代次和版本递增；取消和忙碌均返回明确结果。重复接管请求不会打断手环确认界面。手环可在设置页确认切回手环，晚到的旧手机指令会被代次与版本拒绝。两端不能同时修改共享比赛。

快照携带比分、项目、控制端、代次、名称、显示顺序、历史和最近 64 条指令结果。手环将结果编号与比分一同保存，存储完成才发快照；写入失败保留待写状态，下一次 hello 重试。手机三秒 hello，十秒无快照标记未响应；发现/授权/发送失败可自动重试或手动重试。手机保存镜像、控制端、版本和未确认指令，重启后不会自动变回本地计分。相同比赛的过期快照不应用。首次或不同比赛由用户选择，原手机比赛备份。

本地通过：手环计分回归、接管确认/取消/重复请求、旧版本与非法操作拒绝、重复指令去重、落盘与重载、写入失败重试、200 条重复传输；Android 规则测试及快照类型/比分校验、历史重复应用。Android APK 和 RPK 均构建成功。模拟器用于布局和本地行为，不能证明真机通信。

待真机验收：首次授权、两向计分、退出重进、断线恢复、200 条真机传输的延迟和丢包、20 次断线恢复、前后台及息屏行为。当前手机 USB 断开，尚未完成这组验收。手机称已安装早一轮 1.2.0 APK；最终构建需再次部署核对。手环仍需更新 1.2.0。

当前边界：手机断线暂停新操作；手环保留最终状态，手环控制下可离线计分。尚未实现 PRD 中手机离线独立续记后合并、多份比赛草稿选择和后台服务。因此本版为待真机验收的同步开发版。
