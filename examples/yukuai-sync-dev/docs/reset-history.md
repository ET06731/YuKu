# 1.1.6 比赛操作与历史

第三页为居中圆形长按重置按钮，直径 132 设计像素，中心按钮 108。原生 progress arc 显示两秒长按进度，40ms 更新一次，满两秒归档已完成局并清零。提前松开、手指移动超过 12 坐标单位、切页、后台或销毁均取消进度。持续按住完成后的按钮不会重复归档。

第三页上滑或点击“历史记录”打开独立列表视图；顶部返回按钮及系统返回回到比赛操作页。仍保留主界面横向三页结构。历史卡片仅显示球类、月日与时间、比分。新归档记录保存 timestamp 与 dateLabel，通过原有 storage 队列持久化；旧记录缺少日期时显示“—”。记录顺序保持最新在前，归档规则沿用已结束的比赛，未结束局的重置不会创建历史。
