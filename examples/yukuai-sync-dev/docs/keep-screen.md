# 记分页常亮（1.2.1）

设置页新增“比分常亮：开/关”，默认关，整行点按切换。独立存储键 `yukuai_keep_score_on` 保存手环本地偏好，手机同步不改变该设置。手机控制时仍可切换此开关。

通过官方 `system.brightness.setKeepScreenOn` 实现。仅当应用可见、当前为记分页、没有打开历史且没有退出时申请常亮。切换到其他页、隐藏、销毁和退出时释放；回到记分页后按保存的偏好恢复。关闭开关采用设备正常熄屏策略。偏好尚未载入时暂不接受切换，写入失败回退并显示“设置未保存”，接口失败显示“常亮暂不可用”。滑动后抑制误点击。

本地测试：`node tests/keep-screen.cjs`，覆盖偏好恢复、页面切换、隐藏/恢复、退出/销毁释放、手机控制、滑动抑制和存储失败回退。同步与计分回归通过，RPK 1.2.1 构建通过。真实手环的持续亮屏效果仍需部署后确认。

官方文档：https://iot.mi.com/vela/quickapp/zh/features/system/brightness.html

模拟器实测：336×480 设置页开关完整可见；该模拟器初始化 brightness 模块时返回异常，调用无法成功。应用捕获异常并在开启的记分页返回设置后显示“常亮暂不可用”。此结果不能替代小米手环 8 Pro 真机测试；1.2.1 真机安装尚待 USB 连接恢复。
